# 🚀 WalletInvest - Sistema de Gestão de Carteira de Investimentos

WalletInvest é um sistema completo de gestão de carteira de investimentos desenvolvido em JavaScript/Node.js que permite aos usuários gerenciar seus investimentos de forma abrangente e estratégica. O sistema integra um backend robusto em Express.js com MongoDB para persistência de dados e um frontend responsivo em HTML/CSS/jQuery, oferecendo funcionalidades como autenticação multi-usuário, gestão completa de carteiras (adicionar, editar, remover ativos), busca de cotações em tempo real via Yahoo Finance API, sistema de rateio para distribuição estratégica de investimentos, rastreamento de proventos/dividendos, e categorização de diversos tipos de ativos (ações, FIIs, ETFs, renda fixa, criptomoedas, etc.). O arquivo script.js analisado representa especificamente o módulo de carteira, implementando uma interface interativa para visualização e manipulação de investimentos com cálculos automáticos de lucros/perdas, percentuais de posição, validação de códigos de ativos por categoria, modais para edição e adição de mais cotas, e funcionalidades avançadas como resumo por categoria e atualização automática de preços, tudo integrado a um sistema de notificações e validação de sessão para garantir segurança e usabilidade.

## ✨ Funcionalidades

- **🔐 Autenticação de usuários** com múltiplas contas
- **📊 Gestão de carteira** - adicionar, editar e remover ativos
- **💰 Busca de cotações** em tempo real via Yahoo Finance
- **📈 Sistema de rateio** para distribuir investimentos estrategicamente
- **🏷️ Categorização** de ativos (ações, FIIs, ETFs, renda fixa, etc.)
- **📱 Interface responsiva** com design moderno

## 🛠️ Tecnologias

- **Backend**: Node.js + Express + MongoDB + Mongoose
- **Frontend**: HTML5 + CSS3 + JavaScript + jQuery
- **APIs**: Yahoo Finance para cotações em tempo real
- **Banco**: MongoDB local
